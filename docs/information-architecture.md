# Information Architecture

| Screen | Class | Essential contents |
|---|---:|---|
| Secure Login | P0 | Branding, synthetic notice, predefined demo accounts without embedded passwords |
| Investigation Home | P0 | Recent work, role, jurisdiction, system/source status |
| Investigation Workspace | P0 | Query, source controls, context, results |
| Query Preview | P0 | Intent, filters, identifiers, time, sources, edit/confirm |
| Results | P0 | Case cards, match reason, assurance state, Source Passport |
| Case 360 | P0 | Overview, entities, evidence, timeline, trust issues, sources |
| Case DNA Compare | P0 | Factor breakdown, hard links, differences, penalties, band |
| Evidence Graph | P0 | Bounded graph, legend, filters, edge source drawer, text path |
| Assurance/Challenge | P0 | Agreements, conflicts, missing data, identity uncertainty, alternative explanation |
| Action Impact | P0 basic | Ranked verification gaps, dependencies, safety wording |
| Report Preview | P0 | Watermark, sources, graph/path, warnings, checklist, disclaimer |
| Supervisor Review | P0 minimal | Reports, audits, denials, basic source health |
| Map | P1 | Small contextual map |
| Supervisor Analytics | P1 | Expanded aggregate analytics |

## Visual rules

Police-professional, calm, high contrast; results before prose; expandable explanations; warnings distinct but not alarmist; text and icon badges; colour never the only signal; shortest graph path first; synthetic-data notice persistently visible.

## Report watermark

Every P0 report and print view displays: **SYNTHETIC DATATHON PROTOTYPE — NOT FOR OPERATIONAL USE**.
