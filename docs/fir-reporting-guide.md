# FIR Reporting Guide

## Purpose

ANVAYA reports are bounded, source-scoped records of an investigation. They are factual summaries, not legal advice, prediction, risk assessment, guilt finding, or recommendation.

## Compose and review

1. Open an authorised investigation and choose the relevant FIR case context.
2. Select one or more primary FIR report sections. Duplicate selections are removed in their first selected order; an empty selection is rejected.
3. Provide a plain-text title and optional plain-text analyst note. Markup-like input and oversize notes are rejected.
4. Save a draft, preview the masked/source-scoped result, then submit for Supervisor review.
5. Submitted versions are immutable. Later changes create a new version; review history retains actor, time, and status.

## Primary catalogue

Cover; Investigation Summary; Purpose and Scope; Selected Sources; FIR Search Criteria; Retrieved FIR Cases; FIR Header and Incident Summary; People and Roles; Acts and Sections; Classification; FIR Organisation and Court; Arrest and Surrender Timeline; Chargesheet and Final Report; Evidence; Timeline; Related Cases and Matching Reasons; FIR Relationship Graph; FIR Record Assurance; Sources and Provenance; Source Limitations; Jurisdiction and Masking Notes; Audit Reference; Reviewer Notes; Disclaimer.

Legacy section names remain only for version compatibility and are collapsed in the composer.

## Preview and print

The report-lifecycle preview provides print-safe HTML layout and a structured relationship-graph fallback. Use browser **Print → Save as PDF** only for this HTML report preview. Separately, Case 360 provides **Download cited case brief PDF**, a native server-generated, source-scoped PDF; it is not a browser print.

## Safety and limitations

Reports preserve current role, jurisdiction, selected-source, and masking decisions. They show freshness/reliability/availability limitations when available. They exclude raw source payloads, protected demographics, legacy sensitive entity values, and automatic conclusions. A related-case reason is a factual shared record or fixed temporal context only; it does not establish identity, guilt, common offender status, or recommended action.
