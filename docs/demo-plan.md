# Five-Minute FIR Demonstration Plan

ANVAYA is a synthetic FIR investigation prototype deployed at `https://appsail-50044124045.development.catalystappsail.in/`. This journey uses deterministic fixture data and does not claim access to KSP, CCTNS, or any operational police system.

| Time | Demonstration | What it proves |
|---|---|---|
| 0:00–0:25 | Show `/api/health`, open the public demo, and create the prepared investigation. | Live AppSail hosting, password-free Investigator role, purpose and source boundaries. |
| 0:25–1:00 | Read the Kannada-English golden query and edit the visible interpretation card before execution. | Context-bounded language parsing with a human confirmation gate. |
| 1:00–1:30 | Run discovery and explain candidate-only labeling and source limitations. | Policy-scoped retrieval without identity, guilt, or risk claims. |
| 1:30–2:00 | Open Aggregate Trends; show monthly counts and recorded police-unit volumes. | Real descriptive aggregation, small-cell suppression, and explicit non-forecasting limits. |
| 2:00–2:50 | Open Case 360 and Source Passport; cover FIR, people, legal, timeline, and provenance sections. | Official-dataset-focused case view, masking, and evidence traceability. |
| 2:50–3:30 | Open Related Cases and the FIR Relationship Graph text fallback. | Transparent factual relationships rather than a similarity score. |
| 3:30–4:05 | Open Record Assurance and explain deterministic finding rules. | Data-quality decision support without automatic correction. |
| 4:05–4:35 | Download the cited Case 360 brief PDF. | Native, source-scoped evidence export with limitations. |
| 4:35–5:00 | Close with architecture, safeguards, what is intentionally not claimed, and logout. | Technical honesty, governance, and a credible path to operational integration. |

## Presenter notes

- Use only the synthetic fixture identifiers shown by the UI; do not present a demo account value as a credential.
- Explain that matching reasons are factual observations and do not imply guilt, common offender identity, or a recommended action.
- Source freshness, restricted source access, partial data, empty sections, and unavailable-source messages are expected product states.
- The cited Case 360 brief is the native generated PDF shown in the primary demo.
- Do not show the legacy Case DNA or Action Impact endpoints; those deterministic fixture demonstrations are not part of the finalist story.

## Backup path

If a visual panel is unavailable, continue with Case 360 section cards, the graph text fallback, Record Assurance, and the cited PDF. Keep a local Docker build ready, but do not claim offline mock-data support.

## Deployment-proof boundary

The AppSail URL above is authorised as canonical evaluator evidence. Hosting is proven; production KSP integration, Catalyst Auth/Data Store, and operational fitness are not.
